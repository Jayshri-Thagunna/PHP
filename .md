1. CREATE (The Table)
First, you need a structure. This creates a table with an auto-incrementing ID.

SQL
CREATE TABLE students (
    id INT(11) PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100),
    grade INT(3),
    city VARCHAR(50)
);
2. INSERT (Add Data)
To put information into your table:

SQL
INSERT INTO students (name, grade, city) 
VALUES ('Alex Smith', 85, 'New York'),
       ('Maria Garcia', 92, 'Chicago'),
       ('John Doe', 78, 'Miami');
3. SELECT with WHERE & ORDER BY (Read Data)
This is how you filter and sort your results.

WHERE: Filters the rows.

ORDER BY: Sorts the results (ASC for ascending, DESC for descending).

SQL
-- Get students from Chicago, highest grade first
SELECT * FROM students 
WHERE city = 'Chicago' 
ORDER BY grade DESC;
4. UPDATE (Change Data)
Important: Always use a WHERE clause with Update, or you will change every single row in the database!

SQL
-- Update Maria's grade using her ID
UPDATE students 
SET grade = 95 
WHERE id = 2;
5. DELETE (Remove Data)
Again, the WHERE clause is critical here to avoid wiping the whole table.

SQL
-- Remove John Doe from the table
DELETE FROM students 
WHERE name = 'John Doe';
How to do this in phpMyAdmin UI
If you prefer clicking over coding, here is the flow:

Insert: Click your table name on the left, then click the Insert tab at the top. Fill in the "Value" column.

Select/Search: Click the Browse tab to see all data. To filter, click the Search tab.

Update/Delete: In the Browse tab, every row has an "Edit" (Update) and "Delete" button next to it.

Order By: Simply click the Column Header (e.g., click "grade") in the Browse tab to toggle between ascending and descending order.
